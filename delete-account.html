메이드보카 계정 및 데이터 영구 삭제

Google Play 데이터 보안 정책에 따라 앱을 설치하지 않은 상태에서도 웹에서 직접 메이드보카 계정과 모든 학습 기록을 즉시 영구 삭제할 수 있습니다.

  • 즉시 파기되는 항목: 로그인 계정(이메일·이름·학번), 등록한 모든 단어장 데이터, 단어 그룹, 일일 퀴즈 및 경험치(XP) 기록 전체
  • 보관 기간: 탈퇴 실행 즉시 데이터베이스에서 영구 삭제되며 별도 유예 기간 없이 복구할 수 없습니다.

방법 1. 앱 내부에서 즉시 탈퇴하기

메이드보카 앱 실행 → 하단 [내 정보] 탭 이동 → 화면 하단 [회원 탈퇴] 버튼을 누르고 확인 창에 탈퇴를 입력하면 즉시 파기됩니다.

방법 2. 현재 웹페이지에서 직접 로그인 후 즉시 탈퇴하기

이메일 계정으로 로그인하거나 Google 계정으로 인증한 뒤 아래 삭제 버튼을 눌러주세요.
